# 实现三种风格支持和页面切换功能

## 1. 项目分析

当前项目是一个 Next.js (App Router) 项目，使用 Tailwind CSS 和 Lucide React 图标库。项目已经实现了基本的主题管理系统，支持四种主题切换，但用户希望添加三种特定风格并支持页面切换查看对比效果。

## 2. 实现计划

### 2.1 更新主题系统

1. **扩展 ThemeName 类型**：在 `styles/themes.ts` 中添加三种新风格
   - `dark-cyber` (暗黑风)
   - `swiss-design` (瑞士风)
   - `silicon-valley` (硅谷 SaaS 风)

2. **定义新风格主题**：为每种风格创建详细的主题配置
   - **暗黑风**：深色模式，荧光绿/电光紫强调色，发光效果
   - **瑞士风**：暖白色背景，衬线字体，不对称布局
   - **硅谷 SaaS 风**：浅色模式，科技蓝主色调，Bento Grid 布局

3. **更新颜色映射表**：在 `utils/simpleTheme.ts` 中添加新风格需要的颜色

### 2.2 创建风格切换组件

1. **StyleSwitcher 组件**：创建一个专门的风格切换器组件
   - 显示三种风格的选项
   - 支持实时切换
   - 显示风格名称和预览

2. **集成到导航栏**：将风格切换器添加到导航栏中

### 2.3 更新组件以支持新风格

1. **Navbar 组件**：更新以支持不同风格的导航栏设计
   - 暗黑风：极简导航，荧光色强调
   - 瑞士风：不对称布局，衬线字体
   - 硅谷 SaaS 风：磨砂玻璃效果，科技蓝主色调

2. **Hero 组件**：更新以支持不同风格的 Hero 区域设计
   - 暗黑风：左对齐，渐变色文字，终端打字机效果
   - 瑞士风：超大字体，不对称布局
   - 硅谷 SaaS 风：居中布局，巨大化姓名

3. **ToolCard 组件**：更新以支持不同风格的卡片设计
   - 暗黑风：黑色方块，发光效果
   - 瑞士风：无边框，极简设计
   - 硅谷 SaaS 风：Bento Grid 布局，微质感边框

4. **ExperienceSection 组件**：更新以支持不同风格的时间轴设计
   - 暗黑风：左侧贯穿细线，荧光色点
   - 瑞士风：极简表格形式
   - 硅谷 SaaS 风：标准时间轴设计

### 2.4 实现数据结构优化

1. **创建 lib/data.ts**：根据用户要求，将数据抽离到 `lib/data.ts`
   - 迁移现有的 AI 工具、项目、经历和技能数据
   - 确保数据结构一致，便于不同风格使用

### 2.5 实现页面切换查看对比效果

1. **创建风格预览页面**：创建一个页面，允许用户在不同风格之间切换查看对比效果

2. **添加风格切换逻辑**：确保所有组件都能正确响应风格变化

### 2.6 测试和优化

1. **测试风格切换**：确保所有风格都能正确加载和切换

2. **优化性能**：确保风格切换不会影响页面性能

3. **响应式设计**：确保所有风格在不同设备上都能正常显示

## 3. 技术要点

- **主题管理**：使用现有的订阅模式，确保主题变化能实时反映到所有组件
- **样式实现**：使用内联样式和 Tailwind CSS 结合的方式，确保样式能正确响应主题变化
- **字体处理**：为瑞士风引入 Google Fonts，实现衬线字体效果
- **布局实现**：为不同风格实现不同的布局方式
- **数据结构**：保持数据结构一致，只改变视觉呈现

## 4. 预期效果

用户将能够：
1. 在三种风格（暗黑风、瑞士风、硅谷 SaaS 风）之间自由切换
2. 实时查看不同风格的视觉效果对比
3. 体验每种风格独特的设计元素和布局
4. 保持所有功能和数据的一致性
