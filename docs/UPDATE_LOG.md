# 个人主页版本更新日志

### 主要更新内容

1. **AI数字人聊天组件优化**：
   - 添加具有"神乐"风格的活泼入口，包括悬浮引导气泡、按钮交互和窗口弹出动效

   - 添加加班倒计时项目信息，丰富知识库内容

   - 添加加班倒计时项目，显示四个精选项目

   - 优化悬浮按钮的样式和交互效果

## v1.0 (2026-01-28)

### 主要更新内容

1. **项目初始化**：
   - 创建个人主页基础结构
   - 实现个人信息展示功能
   - 添加精选项目展示
   - 集成AI数字人聊天功能

2. **核心功能**：
   - 个人信息展示：姓名、职位、简介
   - 项目展示：游账、马年新春工具、HRX核心系统
   - 经历与技能展示：工作经历、技能标签云
   - AI数字人聊天：基础聊天功能，可介绍个人项目和背景

3. **技术实现**：
   - 使用React + Next.js构建
   - 采用Tailwind CSS进行样式设计
   - 集成DeepSeek API实现AI聊天功能
   - 实现响应式布局，支持移动端和桌面端
